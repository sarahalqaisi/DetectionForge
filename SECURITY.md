# Security policy

DetectionForge is intended for defensive education and controlled labs, not direct exposure to untrusted networks.

Please report suspected vulnerabilities privately through GitHub security advisories rather than a public issue. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real credentials, private telemetry, or malware samples.

Implemented safeguards and deployment limitations are documented in [docs/SECURITY.md](docs/SECURITY.md).
